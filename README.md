# واجهة — صفحة خدمة وبورتفوليو

موقع عربي متجاوب لعرض خدمة تصميم المواقع ونماذج التنفيذ. اسم «واجهة» عنوان عمل مؤقت قابل للتغيير.

## المحتوى
- الصفحة الرئيسية: `index.html`، تشمل عرض الخدمة، نماذج الشغل، خطوات التنفيذ، والأسئلة المتوقعة.
- نموذج «مساحة» داخل `demo.html` حتى تبقى المعاينة قابلة للتشغيل دون الاعتماد على نطاق خارجي.
- رابط تطبيق «على قدي» الفعلي.
- نموذج يجهّز رسالة واتساب بالرقم الذي اعتمده صاحب المشروع، ولا يرسلها تلقائيًا.

المستودع المستقل `masaha-interior-demo` مخصص لتطوير نموذج مساحة ونشره وحده؛ نسخة `demo.html` هنا عينة مرفقة ويجب مزامنتها يدويًا عند تحديث النموذج.

## التشغيل
المشروع HTML/CSS/JavaScript فقط؛ لا يحتاج تثبيت حزم أو بناء:

```powershell
python -m http.server 8080
```

افتح `http://localhost:8080`. يمكن أيضًا استخدام أي خادم ملفات ثابتة.

## النشر
ارفع جذر المستودع إلى استضافة ملفات ثابتة تدعم HTTPS. لا توجد أسرار أو خادم خلفي أو قاعدة بيانات أو اتصال بتحليلات خارجية. لا تعتمد على روابط المعاينة المؤقتة داخل حملات مبيعات دائمة.

## الملفات
`style.css` للتصميم، و`script.js` للقوائم والفلاتر وتكبير الصور والنماذج، و`assets/` للصور والخط والأيقونة. بعض الأساليب والوظائف مشتركة مع النموذج المرفق، بدون مكتبات تشغيل خارجية.

## الأصول والصدق في العرض
«على قدي» مشروع حقيقي بحسب صاحب المشروع. معاينة الهاتف المصممة بالواجهة توضيحية وليست لقطة من التطبيق. «مساحة» شركة افتراضية، وصورها مولّدة بالذكاء الاصطناعي؛ ليست أعمال عملاء حقيقية.
خط Alexandria ضمن `assets/` مع ترخيصه في `assets/FONT-LICENSE.txt`. لا يُمنح ترخيص عام لكود الموقع أو الأصول الأخرى بمجرد رفعها إلى GitHub.

## التحقق
تمت مراجعة الشكل في متصفح على عرض كمبيوتر ومحاكاة عرض موبايل 390 بكسل، واختبار قائمة الموبايل ومعرض الصور والنموذج التجريبي. لا اختبار جهاز فعلي أو إرسال واتساب فعلي ضمن هذه المراجعة.

لم تُدرج ملفات `.vercel` أو حسابات النشر أو أسرار أو قواعد بيانات مستخدمين في المستودع.
